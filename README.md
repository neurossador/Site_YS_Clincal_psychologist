# Лендинг — Хмарук Юлия Сергеевна

Одностраничный приветственный сайт клинического психолога, специалиста МПЦ [«Нейролекс»](https://neurolex-center.ru/) в Ростове-на-Дону.

## Возможности

- Приветственное окно при первом заходе (запоминается в браузере)
- Hero-блок с кратким представлением и статистикой
- Разделы: обо мне, документы, услуги, подход, клиника, запись
- Галерея документов с просмотром в полноэкранном режиме
- Форма заявки с проверкой полей и подготовкой письма в клинику
- Яндекс.Карта с меткой «Нейролекс»
- Анимации при прокрутке, активный пункт меню, кнопка «Наверх»

## Структура проекта

```
├── index.html      # Разметка лендинга
├── styles.css      # Стили
├── script.js       # Интерактив и карта
├── images/         # Локальные фото и документы (см. images/README.md)
├── package.json    # Скрипт локального сервера
└── README.md
```

## Быстрый старт

Требуется [Node.js](https://nodejs.org/) (для локального сервера).

```bash
npm install   # опционально — зависимостей нет, только скрипты
npm start
```

Откройте в браузере: [http://localhost:3000](http://localhost:3000)

> Карта Яндекса и часть функций корректнее работают через `http://`, а не при открытии `index.html` напрямую с диска.

Без Node.js можно использовать расширение **Live Server** в VS Code/Cursor или любой статический хостинг (GitHub Pages, Netlify и т.д.).

## Изображения

Скопируйте файлы в папку `images/` по списку в [images/README.md](images/README.md). Без них отобразятся только блоки с внешними ссылками (логотип клиники, фото здания с CDN).

## Публикация

1. Залейте содержимое репозитория на хостинг статики.
2. Убедитесь, что папка `images/` загружена целиком.
3. После обновления стилей увеличьте число в `styles.css?v=…` в `index.html` (иначе браузер может показывать старую версию). На опубликованном сайте: **Ctrl+F5** (жёсткое обновление).
3. Форма заявки по умолчанию открывает почтовый клиент с заполненным письмом на `neurolex@inbox.ru`; для автоматической отправки без почты подключите Formspree, Telegram-бот или бэкенд клиники.
