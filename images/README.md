# Изображения для лендинга

Положите в эту папку файлы, на которые ссылается `index.html`:

| Файл | Назначение |
|------|------------|
| `photo.jpg` | Фото специалиста (hero) |
| `doc-1.jpg` … `doc-5.jpg` | Скан-копии дипломов и сертификатов |
| `doc-manchester-ma.png` | Диплом MA in Counselling (University of Manchester) |
| `premia-prodoctorov-2025.png` | Диплом Премии ПроДокторов 2025 |

Фото клиники в галерее подгружаются с CDN сайта «Нейролекс»; при желании можно скачать и хранить локально.
